# Quiz Hub Beta Main

This folder contains the project files restored for local development and Vercel deployment.

## Files
- index.html: main app entry file
- index2.html: copy of the working app page
- admin.html: quick quiz management tool
- quiz-bank.js: loads quizzes from quizzes.json into the app
- quizzes.json: external quiz data bank

## Local run
python -m http.server 8000

Then open http://localhost:8000/index.html
